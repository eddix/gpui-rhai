# Design decision log

Dated decisions that refine the design documents. Grilling decisions from
2026-10-04 are summarized first; later entries record details decided during
implementation. Runtime mechanism decisions also get an ADR.

## 2026-10-04 — grilling consensus

| ID | Decision |
|---|---|
| G1 | Visual sources: cassette futurism (instrument panels), Swiss typography, Rams-era industrial design; lo-fi only for warm neutrals; vaporwave and mid-century graphic design excluded. |
| G2 | Recognizability through five structural signatures (label voice, indicator bar, square lamps, visible shortcuts, keyed tags), each removable through parts. |
| G3 | Default palette: paper, ink and one cobalt spot color. |
| G4 | Normal is quiet: healthy states are neutral; success confirms completed actions and recovery. |
| G5 | Density: size and density are independent axes; density is a declared, inherited environment value; comfortable (32px controls, 14/22 body) is the default for 27-inch 4K displays; compact shrinks heights and outer spacing but not type. |
| G6 | Radius: square by default; roles `sm`/`md`/`lg`; a profile may use a micro radius up to 4px. |
| G7 | The specification governs defaults and choice, not existence: Button keeps seven variants, Tag keeps color variants, the motion pack stays (shown in an Effects group). |
| G8 | Marker system "four silhouettes": Button block, Tag tape, Badge lamp (strong emphasis is a solid block), Kbd keycap. |
| G9 | Focus: 2px reserved border in `focus_ring`, default ink. |
| G10 | Layers: neutral runtime, L0 tokens, L1 components, L2 `layouts/` (neutral) and `patterns/` (opinionated), profiles via `gpui-rhai init --profile`. |
| G11 | Composite components designed from scratch with semantic slots; violations reported by an audit rather than rejected. |
| G12 | Spacing: density-aware scale usable everywhere; relationships expressed mainly by L2 structure; `unit`/`related`/`group`/`section` are optional aliases; the audit checks nesting on resolved geometry. |
| G13 | Content inset contract: one text edge for rows and panels. |
| G14 | Displayed shortcuts derive from actions; the runtime exposes structured bindings. |
| G15 | Composition audit at runtime plus static checks; rule sets come from a profile; no profile means no design rules. |
| G16 | Runtime neutrality: open token registry with component-declared requirements; open typography roles; declarative environment values; token reads and color derivation; Rust-side component derivations move to L0. |
| G17 | Environment values resolve during native rendering (final model for presentation); logic-level environment through deferred construction is a separate proposal (ADR 0023). |
| G18 | Monospace family: system fonts (`Menlo`, then `DejaVu Sans Mono`), no bundled font. |
| G19 | Gallery is rebuilt as a real application from AppShell and L2 with three gates: zero audit findings, keyboard-only scenes, baselines in both densities and modes. |
| G20 | Scope: all 62 components; 0.2.0 with runtime API 3; no compatibility aliases. |

## Implementation decisions

| ID | Date | Decision | Reason |
|---|---|---|---|
| D1 | 2026-10-04 | Dark default accent stays a deep cobalt (`#3d5fe0`) carrying white text; accent-as-text uses the derived `text.accent`. | White text on a blue fill and blue text on graphite cannot both reach 4.5:1; fill identity matters more, and `readable` derives the text color. |
| D2 | 2026-10-04 | Fields have a 2px `border` frame on a `surface_raised` well; pressable controls are blocks. | Tonal fields and tonal buttons would be indistinguishable; the frame marks "you can type here", and a 2px low-contrast frame reads like a 1px line while reserving the focus border. |
| D3 | 2026-10-04 | Outline treatments draw their frame with the reserved 2px border in the `border` role. | GPUI paints one uniform border per quad; a 2px low-contrast line has the visual weight of a 1px line and avoids nested focus nodes. |
| D4 | 2026-10-04 | Tabs labels keep weight 400 in both states. | Changing weight on selection makes slot widths jitter. |
| D5 | 2026-10-04 | The label voice uses the mono family because GPUI 0.3.7 has no letter spacing. | Uppercase proportional text without tracking is cramped. |
| D6 | 2026-10-04 | `SF Mono` is not used as a family name. | CoreText does not resolve it by name and silently falls back to Helvetica, which is not monospaced. |
| D7 | 2026-10-04 | Markers keep 20px height and their padding in both densities. | Markers sit inside rows; shrinking them in compact rows harms CJK legibility without saving space. |
| D8 | 2026-10-04 | Button's default variant is `secondary`. | "Normal is quiet": an unqualified Button must not compete with the one primary action of a region. |
| D9 | 2026-10-04 | Control text uses `control_small` (13/16) and `control_regular` (14/20) instead of the body roles. | Specimen measurement: a 22px body line plus the reserved 2px focus border made compact `sm` controls 26px instead of 24 and `xs` 24 instead of 20. Font sizes are unchanged, so density still never changes type size. |
| D10 | 2026-10-04 | The Tag segment prop is `facet`, the derived color `tag.facet`. | `key` is the reserved component instance key. |
| D11 | 2026-10-04 | Runtime gains `group_focus` and `focus_within` styles; focus-styled nodes now honor their tab stop policy. | A compound control (Checkbox, Switch, Tabs, list rows) must show focus on its mark without moving the content edge; field groups must frame a native input's focus. GPUI applied the element tab policy only to handles it creates, so persistent handles were never tab stops. |
| D12 | 2026-10-04 | ToggleGroup uses roving focus over its segments. | The previous single-tab-stop group had no visible keyboard cursor. |
| D13 | 2026-10-04 | Overlays gain a cross-axis `align`; menus and field panels open start-aligned. | Centered dropdowns drift away from their trigger and get clamped at window edges. |
| D14 | 2026-10-04 | Table, ScrollArea, CodeViewer and DiffViewer draw no outer frame. | Regions provide edges; framed content inside framed regions doubles the lines. |
| D15 | 2026-10-04 | Button shows its shortcut legend at every size. | Rhai cannot read the resolved size; the caller omits the legend for `xs`. |
| D16 | 2026-10-04 | `ctx.action_enabled(id)` is read at render and is not dependency-tracked. | Components re-render with their parent; a host that changes enablement without other state change must trigger a render. |
| D17 | 2026-10-04 | Chart palettes 5 and 8 derive from accent/success and accent/danger mixes. | Hue separation rules leave too few independent hues in most palettes. |
| D18 | 2026-10-04 | Fill-height virtual lists defer their first reveal until the viewport is measured. | Without a configured height there is no estimate; revealing early top-aligned the target and hid preceding group headers. |
| D19 | 2026-10-04 | `ScriptApplication` writes fatal startup errors to stderr before quitting. | On macOS quitting terminates the process, so `run` never returned the error. |
| D20 | 2026-10-04 | The Gallery is a Rhai application on `patterns/app_shell` (`registry/gallery/`); the Rust Gallery shell is removed. The Host adds only the Cmd+K binding, page sources as native documents and the live audit count. Stories stay as development fixtures and `--story` opens one in a standalone window. | An acceptance application written with the public patterns tests them; a Rust shell would hide exactly the composition problems the Gallery must expose. |
| D21 | 2026-10-04 | Table with a selection mode is a tab stop: Up/Down/Home/End move the selection, Enter emits `row_click`, and the focused table frames the selected row with `group_focus`. | Productivity tables are read and operated by keyboard; the selection doubles as the keyboard cursor, so no second roving state is needed. |
| D22 | 2026-10-04 | Audit refinements: nesting compares gaps on the same axis only; a `justify_between` row's gap is a floor; a heading-led container sets no limit; controls, markers and painted boxes align by their own edge; label-voice text and children that contain controls are left out of mixed-type; overlay content starts a fresh scope; the font check accepts any resolving fallback; `.audit_allow([...])` opts a node out. | Each refinement removed a false positive found on real Gallery pages without hiding a real problem; every remaining finding on the Gallery was a composition fix. |
| D23 | 2026-10-04 | TitleBar and StatusBar regions: start and end share the free width (`flex_basis(0)`, grow), the center never shrinks, the start truncates first and the end never shrinks below its controls. | The Gallery title bar clipped its own controls when the title was long. |
| D24 | 2026-10-04 | Region footer fields sit `group` apart. | Footer fields are groups (status, count, time); `related` read them as one phrase. |
| D25 | 2026-10-04 | `justify_start`/`justify_end` follow the flex direction (`FlexStart`/`FlexEnd`), so they mirror in RTL rows. | GPUI's `start`/`end` are writing-mode values that stay physical under `row-reverse`; RTL title and status bars put their end region in the middle of the window. |
| D26 | 2026-10-04 | TitleBar shows title and subtitle on one line at one size, told apart by weight and color. | Two lines (20 + 16) do not fit the 32px compact title bar and barely fit 36px. |
| D27 | 2026-10-04 | A disabled Button keeps its variant's silhouette: blocks become a neutral block, outline keeps its frame, ghost stays bare. | A disabled ghost (Pagination's previous page, a disabled Toggle) suddenly grew a block and looked like the most important control. |
| D28 | 2026-10-04 | A horizontal Slider or RangeSlider is a 240-wide unit; label and value span exactly the track. | In a wide column the value drifted to the far edge, away from the track it describes. |
| D29 | 2026-10-04 | Icon declares `help`, `info` and `warning`; a registry test requires every bundled asset to be declared by some module. | Declarative assets are preloaded only when a module declares them; dropping Alert's icons in 0.2 left `info` and `warning` impossible to draw. |
| D30 | 2026-10-04 | Stacked DescriptionList: a term sits `unit` above its value, pairs stand `group` apart. | With no gaps (or `related`, only 4px more than `unit`) the pairs did not read as pairs. |
| D31 | 2026-10-04 | A Table column whose row has no value of its own shows only its adornments. | A status column showed the state twice, as text and as a badge. |
| D32 | 2026-10-04 | Gallery baselines are rendered offscreen (`VisualTestAppContext`, `Window::render_to_image`) in device pixels; the 38 example baselines stay as 0.1.x captures until a refresh pass. | Screen capture depended on the window manager (a tiling manager resized the window) and could include other windows; offscreen readback is deterministic. |
| D33 | 2026-10-04 | Application scripts must not define functions named like built-in methods (`index_of`, `contains`, `len`, …). | Rhai lets a script function be called as a method and resolves script functions before built-ins, also inside imported modules: the Gallery's `fn index_of(values, key)` captured Command's `s.index_of(c, position)`, and the failing render rolled back silently. |
| D34 | 2026-10-05 | Every interactive component is exactly one tab stop (a census test enforces it). An overlay's trigger wrapper is a stop only when its trigger content cannot take focus; a container with key handlers is a stop only when it holds no focusable child; tooltip panels are never stops; Dialog's empty anchor does not activate. | Select and Combobox had three stops, Popover, Tooltip, DatePicker and ToggleGroup two, and a closed Dialog one: Tab landed on wrappers that showed no focus, which reads as a broken keyboard. |
| D35 | 2026-10-05 | In RTL, a child with a definite width inside a stretching column sits on the start (right) edge. | Flex layout has no direction; such children stayed on the left while their column's text moved right. |
| D36 | 2026-10-05 | The audit compares right edges in RTL views, and a cell that centers its content aligns by its own edge. | Text starts are right edges in Arabic; centered weekday labels and day numbers have no start edge to align. |
| D37 | 2026-10-05 | FormLayout controls keep their own width, and helper text sits a `unit` under the control; the Textarea counter sits `xxs` under its field. | Stretched toggle groups looked like web forms; the counter belongs to the field and must sit closer than the form's helper text. |
| D38 | 2026-10-05 | DataView footer fields sit a group apart, its start and end ends distributed; a Table badge that repeats its cell's value replaces the text; identifier values and long options truncate instead of wrapping or clipping. | Pagination inside the footer, a status column grouped by its own field, and narrow embedded views. |
| D39 | 2026-10-05 | The five visual examples are written with the 0.2 layouts and patterns and pass the productivity audit (a test enforces it); their baselines are offscreen captures driven by the same `view(...)` builders the examples run. | Examples are what people copy; 0.1-style literal geometry in them would teach the old system. |
| D40 | 2026-10-05 | A stretched child of a column without a width of its own renders with a definite `width: 100%`. | Taffy otherwise measures it at content width and lays it out again stretched, and the passes compound per nesting level: Gallery frames took 20 to 52 ms of layout and now take about 2 ms, pixel-identical. |
| D41 | 2026-10-05 | `ScriptViewHandle::committed_revision` lets Hosts skip work on frames that only repaint; the Gallery audits once per revision, and system font names are cached. | The Gallery ran a 100 ms audit (almost all font enumeration) after every frame, so hover and scrolling stuttered. |
| D42 | 2026-10-05 | `UiNode` is a shared copy-on-write handle (`Rc`), mutated through `make_mut`. | Rhai copies values on every variable read, array push and call; deep-cloning node subtrees was about half of each Gallery render (navigation 15 ms to 7.4 ms, a keystroke 10.6 ms to 5.1 ms). |
| D43 | 2026-10-05 | A failed transaction's error stays reported until a successful reload, the banner's Dismiss button or `ScriptViewHandle::clear_error`; automation commands compare a failure counter instead of clearing it. | The failure rolls the view back and the view keeps working, so the next event succeeded and cleared the error within a frame: Resizable's drag failed on every release and nobody could read why. |
| D44 | 2026-10-05 | A controlled component's change payload is exactly the next value of the prop it controls; Resizable's `resize` drops `handle`. | Two of the four Resizable callers stored the payload as the rect and broke; every other controlled event (`move`, `transform_change`, `rotate`) already followed the rule. |
| D45 | 2026-10-05 | The Gallery demonstrates PanZoom over a plane larger than its viewport, with the transform and a Reset view button, and Rotatable without a handle. | A small grid inside the viewport made panning look like one shape jumping away; a corner handle far from the arm made Rotatable look dead. |
| D46 | 2026-10-05 | `gpui-rhai check` warns (`builtin-shadow`) about entry functions that take over a native function: `fn f(a, b)` captures method calls `x.f(a, b)` and direct calls `f(a, b)`. Always on, not a profile rule; tests keep the Gallery, stories, Theme Studio and example apps clean. | The failure is silent (the captured call fails inside a component and the render rolls back). The lint found the same `index_of` hazard in two stories and latent ones in two examples (`filter`, `split`). |
| D47 | 2026-10-05 | `ctx.theme_variants()` lists the loaded variants; the Gallery picks any of them from a title bar Select and launches with any bundled theme slug. Light/dark becomes a palette command that switches within the current family. | Only Default and Catppuccin have both modes; a light/dark button could not reach the other thirteen themes. |
| D48 | 2026-10-05 | `.window_drag_area()` lets a node replace the platform title bar: its background moves the window, a double press runs the platform title-bar action, a press a focusable control takes stays with the control. It is inert unless the Host allows it for the view (`window_drag_areas`). TitleBar and AppShell gain `window_drag`; on macOS the Gallery hides the platform bar (transparent titlebar, `app_owns_titlebar_drag`) and leaves 72pt for the window buttons. | The earlier rule that a bar alone never changes native behavior protects embedded views; the Host permission keeps that guarantee while letting an application draw its own chrome. |
| D49 | 2026-10-05 | Corners are an environment axis (`square` default, `subtle`, `round`); radius roles depend on it and gain `xs` for boxes. `round` makes controls and markers capsules and square controls circles, keeps panels at 8px, and leaves Checkbox a box, status lamps square and faders rectangular. Joined groups round only their outer corners through the new logical `radius_start` / `radius_end`. | Users asked for rounded styles; making it an axis whose default is all zero keeps the square design pixel-identical, and the exceptions keep the distinctions the design depends on (Checkbox versus Radio, the lamp signature). |
| D50 | 2026-10-07 | Toolbar gains one `fill` slot: a node between the start and end groups that takes the free width, at least `metrics.label_column`, with a flex basis of that minimum so the bar wraps on the minimum, not on the field's content. Empty groups add no gap, so the fill can end up first, between or last; it cannot sit inside a group. DataView passes `fill`, `size` and Region's `inset`, not `part_styles`. | A content-sized filter group gives `width: relative(1.0)` nothing to resolve against (a 36px field in oh-my-byted); a long placeholder wrapped the bar. One slot keeps the start/end grammar instead of a free layout. |
| D51 | 2026-10-07 | Region's body clips by default; `scroll: true` scrolls it with the header, toolbar and footer fixed. `external_title` marks a region whose title is drawn elsewhere (`.heading_elsewhere()`), exclusive with `title`. | Tables and virtual lists scroll themselves, and a scrolling wrapper around them would fight their viewport; the option makes the 0.1 page behavior explicit. |
| D52 | 2026-10-07 | Table group headers use the label voice. | A group header is structure, like a column header; body weight 600 competed with the data. |
| D53 | 2026-10-07 | A container that holds focus itself shows the 2px ink frame over its edge and hairline (part `focus_frame`), never next to a control's own frame; a cursor shows where keys act inside. The view owns overlay panel focus handles so panel content sees the panel's focus through `group_focus`. | Overlays were 1px hairlines or showed nothing while controls and AppShell regions showed 2px; one rule covers every focus owner, and drawing over the edge keeps layout fixed. |
| D54 | 2026-10-07 | AppShell's scope is a single-window tool shell with fixed side widths; resizable or collapsible side bars, several panels on one side and floating tool windows stay in application shells built from Region, TitleBar and StatusBar. | Covering every shell would make AppShell a layout engine; the parts already compose. |
| D55 | 2026-10-07 | The monospace face is a typography role (`code`) in the token base, not a palette field: a Host or `ui/tokens.rhai` changes it, and a palette switch never changes a face. A Table column takes a role (`typography: "code"`), applied in full and exempt from `mixed-type-in-row` on its row; a span takes only the role's family and weight, so it stays on its line. | #95 asked for "switching theme changes the mono face"; in 0.2 themes are palettes, so the acceptance becomes the role. Mono at 13px sits optically with 14px body text in a row; inside a paragraph a size change would break the line box. |
| D56 | 2026-10-07 | Components inside a virtual item are named by the item: `VirtualCollection[key]/Item[<item key>]/...`. | A keyless component's automatic key counted occurrences across one realization batch, so a new row could take a retained row's path (#110); the item key is stable, and keys inside a row need only be unique in it. |
| D57 | 2026-10-07 | An overlay's identity is (declaring component instance, key); Layers likewise. `parent` resolves to the nearest enclosing overlay with that key, else one the same instance declared. `overlay_placement(view, key)` keeps its arguments and reports an ambiguous key as an error; `overlay_placement_in` names the instance. A shared-layout group belongs to the instance that named it. | Most script identities (element refs, signals, timers, virtual collections) were already per instance; overlays were per view, so dismissal went to the last-rendered instance (#109). A submenu is declared by its own Menu instance but rendered inside its parent's content, so parents resolve through the render ancestry, not the owner. |
| D58 | 2026-10-07 | Capability calls carry an `InvocationContext`: origin (user input with the event name, automation, timer, task completion, subscription, effect, lifecycle), view and component. Timers and task completions record the root origin that started them. Host key-binding actions and window closes are user input. The runtime keeps one origin slot set per dispatch path; actions and component events queued during an invocation carry its origin and run with it. `call_with` defaults to `call`. | Hosts gate user-activated capabilities; a time-window heuristic misattributed clicks across views and could not see inside occluded overlays (#91). One slot set on dispatch costs nothing on the render path. |
| D59 | 2026-10-07 | Table emits `context_request` and draws no menu. A right press selects the row first (replacing the selection unless it holds the row; nothing without a selection mode); Shift+F10 and the menu key ask for the current row with its bounds as the anchor. | The caller owns the menu's items and actions; selecting first matches desktop file lists, and keeping a multi-selection lets one menu act on all of it. |
| D60 | 2026-10-07 | A resize grip is decoration owned by the component: SplitPane draws it last in the end pane at the separator, Resizable after its handles, so it paints above the panes without a z-index. The native handle keeps the gesture, keyboard steps, role and tab stop; the grip counts as the handle for presses and hover where it is visible and not covered (a node with an element ref records a hitbox in its place in paint order). Its look follows a native string signal through `.signal_style`, a general node API. The native line stays the default (`line`, `line_inset`). | GPUI has no stacking order and a script cannot defer paint; placing the grip in a later sibling is enough. A signal-selected style keeps pointer moves off the Rhai path, as the drag preview already is (#83). |
| D61 | 2026-10-07 | Fields (Input, Textarea, Select, Combobox and DatePicker triggers, InputGroup affixes) take `metrics.field_pad`, about 1.4 times the vertical gap between the frame and the text (comfortable 5 / 7 / 10 / 12, compact 3 / 4 / 6 / 10), nudged to nearby structure: md text on `metrics.inset`, room for the caret at compact xs, the spacing scale at lg. Textarea's vertical padding `metrics.multiline_pad` comes from the same ratio less the half-leading. Button, Tabs and ToggleGroup keep `metrics.control_pad`. | Fields used the button padding, 2.3 times the vertical gap at md (16 against 7), so typed text looked as if it began with a space. A ratio rather than one offset keeps small and large fields in proportion. |
| D62 | 2026-10-08 | List is a component for keyed rows without columns (#119): a leading status Badge, title, secondary text and meta as item data, Table's selection, keyboard and context-request model, `metrics.inset` on every row. Rows are data, not caller nodes. DataView gains `bleed` (default true). | Applications hand-drew clickable rows (36 in oh-my-byted and its plugins) and each got the inset, hover, selection or keyboard wrong. Data rows virtualize: a virtual collection's items are values, so arbitrary nodes per row would mean rendering every row. A body that is not Table or List could not keep DataView's inset. |
| D63 | 2026-10-08 | Runtime: `group_hover` paint styles (the nearest ancestor with a `hover` style); `.translate_wheel()` for one-axis scroll containers; `scroll_into_view` reveals a direct child minimally through `scroll_to_item`, defers a request for a node mounted or ref'd in the same transaction and drops one whose node was unmounted; the sortable item primitive takes `take_focus: false` and `tap: true`. Rhai is built at `opt-level = 1` in dev profiles. | TabBar needs a close button that shows on row hover, a strip that a mouse wheel scrolls, a reveal that does not jump a visible tab to the edge and works the frame a tab opens, and tabs that both select and drag. The Theme Studio and design stories render every component and needed about 2.1MB of a 2MB test-thread stack in debug builds. |
