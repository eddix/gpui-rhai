# gpui-rhai 0.3.0

Release date: 2026-10-27. A minor release that is **not compatible** with 0.2.3;
read [Not compatible with 0.2.3](#not-compatible-with-023) before upgrading.
Runtime API stays **3**, gpui-pre/core/platform stay 0.3.7 and MSRV stays 1.95.
Upgrade core, registry and CLI together.

It folds TabBar into Tabs, which now has three looks (`track`, `underline`,
`bar`) that share counts, closing, adding, reordering, slots and an all-tabs
menu; adds the Dracula, Molokai and Absolutely themes; groups the Gallery by the
chapters of the design contracts; keeps named callbacks in their module's
environment; reports recoverable image failures and every view failure to the
Host; and adds responsive grid tracks, aspect ratios and CSS cubic-Bézier
easings. The full list is in the [CHANGELOG](../../CHANGELOG.md).

## Not compatible with 0.2.3

- **TabBar is removed.** Use `Tabs(#{ variant: "bar", panel: false, ... })`:
  the tab fields (`closable`, `dirty`, `icon`, `disabled`), `start`/`end`,
  `overflow_menu`, `reorderable` and the `change`, `reorder` and
  `context_request` events carry over. `on_close` now receives
  `#{ value, next }`, where `next` is the tab to select instead. The arrows
  select directly: there is no separate cursor and no Enter step. `key` is
  required only with `reorderable` or `overflow_menu`. See decision D71.
- **Tabs behavior.** Tabs reveals the selected tab through an effect, so it
  renders inside a mounted view (every application does); a test that renders
  a view once without a `ScriptLifecycle` must mount it. Content-width tabs keep
  their width, up to two label columns, and the strip scrolls instead of
  squeezing them. The tablist now sits inside a `strip` part, so code that
  walks the node tree finds it one level down; `part_styles` keep working.
- **Token base.** Tabs reads `metrics.counter`, the `counter` typography role,
  `tabs.counter` and `control.hover`. `gpui-rhai update` brings them into an
  unmodified or baselined `ui/tokens.rhai`; a hand-edited copy without a
  baseline must take the new lines from `registry/tokens.rhai`, or the theme
  fails to load with `lacks tokens required by components/tabs`.
- **Rust API.** `MotionEasing` gains a `CubicBezier` variant: an exhaustive
  `match` needs an arm (#186). `ScriptViewConfig::on_error` and its
  `ScriptErrorReport` are new (#185, #205), so they break nothing.

## Upgrading from 0.2.3

Upgrade the CLI first, then run `gpui-rhai update`:

- **Tabs and its new dependencies.** `update` merges `components/tabs` 0.3.0
  and installs what it now imports: `components/tab_overflow_menu` (new) and
  `components/icon_button`, with the `close` and `plus` icons.
- **A copied TabBar stays yours.** `update` leaves `ui/components/tab_bar.rhai`
  and its baseline alone with a `note:` line, and updates everything else; the
  copy keeps running until you migrate its callers and remove it.
- **New themes.** Dracula, Molokai, and Absolutely Light and Dark join
  `ui/themes/`; existing palettes are untouched.
- **Versions.** Modules changed in this release take 0.3.0 (Tabs,
  TabOverflowMenu, AnimatedTabs); the authoring guide now states the rule.

Merges keep local edits and write conflicts to `.gpui-rhai/conflicts/`.
