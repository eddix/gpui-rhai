# gpui-rhai 0.2.1

Not released yet. A compatible patch release of 0.2: Runtime API stays **3**,
gpui-pre/core/platform stay 0.3.7 and MSRV stays 1.95. Upgrade core, registry
and CLI together.

It fixes what applications met after moving to 0.2.0 and adds small APIs; the
full list is in the [CHANGELOG](../../CHANGELOG.md).

## Upgrading from 0.2.0

### Copied official components

`gpui-rhai update` brings the eleven modules that changed, now at 0.2.1:
`components/code_viewer`, `components/combobox`, `components/command`,
`components/command_dialog`, `components/list`, `components/menu`,
`components/resizable`, `components/tab_bar`, `components/table`,
`layouts/region` and `patterns/data_view`. It merges them with local edits as
usual and writes conflicts to `.gpui-rhai/conflicts/`.

### The token base

`ui/tokens.rhai` belongs to the application, and `update` does not overwrite an
existing one. To keep text at 4.5:1 on the facet of a Tag and on selected Table
and List rows (#134), change two derived colors in it:

```rhai
// before
"tag.facet": mix(theme_color("surface_hover"), theme_color("text_primary"), 0.14),
"table.selection": mix(theme_color("surface"), theme_color("accent"), 0.28),
// after
"tag.facet": readable(mix(theme_color("surface_hover"), theme_color("text_primary"), 0.14),
    theme_color("surface_hover"), theme_color("text_primary"), 4.5),
"table.selection": readable(mix(theme_color("surface"), theme_color("accent"), 0.28),
    theme_color("surface"), theme_color("text_primary"), 4.5),
```

Hosts that load `gpui_rhai_registry::TOKEN_BASE_SOURCE` get it with the crate.
Among the bundled themes only Everforest and Gruvbox change.

### Behaviour to check

- Table group headers show the group value in its own case (#146). Styles do
  not change case; a caller that wants uppercase headers uppercases the values
  it groups by.
- Selected List rows draw secondary and meta text in `text_primary`.
- The panels of Menu, ContextMenu, Select, Combobox, Command and CommandDialog
  pad every side by half of `radius.lg` (D69). In the square style they lose
  the 4px above and below their rows, so an open list is 8px shorter (Command
  4px); in the subtle and round styles every side is inset by 2px or 4px.
- Region's footer wraps and clips at the region's edge (#137); a footer that was
  laid out to run past the region now takes a second line.
- Line breaks in text typed or composed into a single-line field become
  spaces, and input that is only line breaks is ignored. On macOS Return never
  reached the field as text, so Enter behaves as before.
- Combobox emits `submit` only when the caller passes `on_submit`; without it
  Enter behaves as before.

### Hosts (Rust)

All additions; nothing existing changes signature:

- `ScriptViewHost::open_overlays()` and `ScriptViewHost::dismiss_escape(window, cx)`,
  with the new `OpenOverlay` (#147); see [embedding](../embedding.md).
- `AsyncCapabilityHandler::start_with`, `SubscriptionCapabilityHandler::subscribe_with`,
  `CapabilityRegistry::start_task_with` and `start_subscription_with` (#133);
  see [capabilities](../capabilities.md).
- `HostFunction`, `HostFunctionError` and `RuntimeEngine::lint_known_calls_with_host`
  (#141).
- `gpui_rhai_cli::CheckReport` gains `host_extensions`: code that builds or fully
  destructures a `CheckReport` with a struct literal needs the field.

### Projects with Host extensions

`gpui-rhai check` reports calls to functions and primitives the Host registers.
Declare them in `ui/app.toml` so `check` treats them as known (#141):

```toml
[host]
functions = ["open_file/1", "omb::status/0"]
primitives = ["OmbChart"]
```

`gpui_rhai::HostSlot` needs no declaration.

## Known gaps

- Focus visibility: a focused List with a selection mode and nothing selected
  shows no frame; a ContextMenu trigger area without its own control is a tab
  stop with no frame; an AppShell region is a tab stop before its controls.
- Resizable's corner grips show the default cursor: styles have no diagonal
  resize cursor yet.
- Toast's stacked presentation (#148) is planned for 0.3.
- An Input keeps painting its selection after focus moves to another field.
- Window drag areas do nothing on Windows: GPUI's Windows platform implements
  neither the window move nor the title-bar double press they call, so a Rhai
  title bar there neither moves nor zooms the window.
- On Linux a span's typography role uses the role's first font family only;
  whether a missing `code` family falls back to DejaVu Sans Mono there is
  unverified.
- IME preedit and VoiceOver are checked by hand.
