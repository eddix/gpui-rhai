# gpui-rhai 0.1.7

Status: implementation candidate; not yet published.

0.1.7 adds the formal acceptance application and source-backed story system.
It keeps Rhai Runtime API **2** and builds on the gpui-pre/native-accessibility
0.1.6 candidate. Do not publish 0.1.7 before the stacked 0.1.6 platform and
upstream gates are complete.

## Gallery and reference application

- `gpui-rhai gallery` opens Explore plus the Operations Workbench. `--list`
  prints the stable catalog without creating a window; `--story`, `--case`,
  `--theme`, and `--locale` select deterministic bundled inputs.
- Explore searches titles, IDs, keywords, and module IDs; filters registry
  categories; isolates and caches story state; resets only the current story;
  and displays the exact running Rhai source in CodeViewer.
- Auto/Compact/Regular/Wide use the real mounted content width and Runtime
  breakpoints. Normal/Reduced/None uses the public Host motion policy. Theme,
  locale, viewport, and Motion changes preserve story business state.
- Registry-driven coverage includes all 51 official components, ten Motion
  components, Chart adapters/series, the native streaming baseline, and a real
  HostSlot resident-form story. Missing public-module coverage fails tests.
- Operations Workbench is a connected Rhai application over Rust-owned
  fixtures, `NativeCollection`, `NativeChartData`, and a bounded subscription
  capability. It includes Dashboard, searchable/sortable/paged/grouped Hosts,
  Configurations/Code/Diff, deployment confirmation/progress/failure,
  Settings, CommandDialog, Sheet, Toast, and keyboard behavior.
- Cases cover normal, cancel, loading, empty, partial failure, streaming,
  1,000-row large data, configuration diff, and Host theme overrides.

## Runtime and component changes

- `ScriptViewHandle::{select_theme, select_locale, set_motion_preference}` lets
  a trusted Host change the environment without reconstructing a view.
- HostSlot no longer marks every key handled at the boundary. Resident Input
  and Textarea receive normal IME insertion; pointer/wheel/click isolation and
  Host lifecycle authority remain intact.
- Table columns accept up to four structured semantic Badge adornments for both
  Array and NativeCollection rows. Table also adds controlled
  `query`/`search_fields` and one-based `page`/`page_size`; NativeCollection
  performs full-source sort, filter, paging, and grouping in Rust before
  virtual projection.
- Plain wheel over Chart bubbles by default; `interaction.wheel_zoom` selects
  `off`, `modifier`, or `always`. Blank titles no longer reserve a title band,
  and specialized adapters no longer invent content titles.
- Invalid Chart spec/data rejects the event transaction, reaches `last_error`,
  preserves the last-good figure, and marks the view/figure invalid with the
  exact diagnostic description.
- Chart cross-axis/relative-height presentation and content-bearing Tabs have
  native geometry regressions. Tabs now proves fill-height Table and Chart
  panels rather than relying on a source-string assertion.

## Example and verification migration

- The former `component_gallery`, `motion_gallery`, and `chart_gallery` Cargo
  targets are removed. Use `gpui-rhai gallery --story components/catalog`,
  `motion/catalog`, `charts/catalog`, or `charts/streaming`.
- Copyable tutorials stay at the top level. Performance probes and native smoke
  targets moved under `crates/gpui-rhai/examples/internal/` with explicit Cargo
  target paths, so their target names remain stable. `examples/README.md` is the
  single index.
- Native tests mount/draw every story/case, execute normal/cancel/failure and
  overlay workflows, hot-switch all bundled themes, verify HostSlot Chinese
  input, and check producer cleanup across suspend/resume.
- The release benchmark reuses `charts/streaming` with 100,000 Host-owned
  points and asserts zero streaming Rhai operations. Release smoke launches
  Gallery from an empty temporary working directory and rejects any file write.

## Integration checklist

1. Upgrade all three crates together once 0.1.7 is published.
2. Run `gpui-rhai update` and review Table source/schema changes.
3. Replace removed Gallery example commands with `gpui-rhai gallery`.
4. If a Host changes theme/locale/Motion after mount, use the new
   `ScriptViewHandle` methods rather than recreating the view.
5. Run `gpui-rhai gallery --story apps/operations --case config-diff` and the
   application-specific dogfooding workflow before release.

The Omarchy adapter, arbitrary UI zoom, third-party story plugins,
Browser/WASM, CodeEditor, Terminal/SSH, real command execution, network
services, persistence, 3D, and Windows certification remain outside 0.1.7.
