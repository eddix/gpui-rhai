# gpui-rhai 0.1.0

The first public release established the Rust runtime, editable source registry
and CLI/Theme Studio as one versioned product.

## Highlights

- Retained declarative `UiNode` rendering from Rhai with file and embedded Host
  APIs, hot reload, transactional state/store updates and restricted imports.
- Native GPUI input, overlays, virtual collections, Canvas, CodeViewer and
  DiffViewer.
- Typed capabilities and custom primitives, themes, locales, assets, RTL and
  multi-window lifecycle.
- 50 source-owned components and 15 bundled themes.

## Adoption

```bash
cargo install gpui-rhai-cli --version 0.1.0 --locked
gpui-rhai init
gpui-rhai check
```

There is no earlier public release to migrate from. See the tagged
[`CHANGELOG.md`](https://github.com/eddix/gpui-rhai/blob/v0.1.0/CHANGELOG.md)
for the complete initial contract.
