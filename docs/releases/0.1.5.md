# gpui-rhai 0.1.5

0.1.5 keeps Runtime API **2** and adds the optional native Chart Runtime plus a
complete theme-driven component pass. It is not an ECharts compatibility layer:
Rhai continues to use GPUI Rhai's typed component, data, event, Motion,
extension and security boundaries.

## Chart Runtime

- Compose Cartesian2D, Polar and Host-owned Geo2D regions with multiple named
  axes/grids. Built-ins cover Bar/Stacked Bar, Line/Area, Scatter, Pie/Donut,
  Heatmap, Map/Choropleth, GeoScatter, GeoLines, Candlestick, Radar, Gauge and
  Funnel.
- Small Rhai row arrays become typed columns once. Revisioned
  `NativeChartData` supports atomic replace, concurrent-safe append and sliding
  windows without per-update Rhai execution.
- Rust-native filter/sort/aggregate/bin/stack/normalize/moving-window/LTTB
  transforms preserve semantic identity and null gaps.
- Native tooltip, crosshair, zoom/pan, brush, keyboard navigation, selection,
  annotations and linked charts share one prepared paint/hit/semantic/export
  scene.
- Controlled viewport proposals carry an exact coordinate-typed `viewport`
  plus `viewport_revision`. Scalar zoom/pan remains shorthand; independent X/Y
  windows and normalized Geo cameras round-trip without information loss.
- Host extensions may register GeoJSON/SVG maps, projections, transforms,
  formatters and validated custom series. The crate bundles no map data,
  network/geocoding authority or per-datum Rhai renderer.
- Host-only SVG/PNG export uses the same terminal scene and resolved title/
  body-small typography as native presentation.

Enable it explicitly:

```toml
[dependencies]
gpui-rhai = { version = "0.1.5", features = ["charts"] }
```

```bash
gpui-rhai add chart
cargo run --release -p gpui-rhai --features charts --example chart_gallery
```

## Theme and component system

- `ThemeTokenOverrides` applies validated color, spacing, radius, typography,
  motion and arbitrary namespaced preferences across file/embedded themes,
  theme switching and hot reload.
- Complete immutable theme snapshots preserve custom namespace colors in
  ordinary, virtual, overlay and native-primitive paths.
- Official component spacing is mapped to `xxs/xs/sm/md/lg`; only explicit
  structural constants remain. Custom themes must now define `spacing.xxs`
  (the bundled baseline is 2px).
- Tabs uses measured typography plus token padding instead of fixed track/slot
  heights. `tabs.foreground` preserves secondary hierarchy while reaching
  4.5:1 against the actual track across all bundled themes.
- Table uses a distinct `table.selection` surface. Button/Badge retain an
  action-versus-label density hierarchy without hard-coded theme exceptions.
- Chart native labels, tooltips, plot margins and SVG/PNG text share the Host's
  resolved typography family, fallbacks, size, line height and weight.

## Runtime hardening

- Requested, prepared, candidate and presented Chart frames have distinct keys
  and foreground commit boundaries.
- Streaming coalesces while suspended; motion time freezes; resume completes
  only after native prepare, script transaction and native commit.
- Failed lifecycle compensation disposes the affected view rather than
  advertising partially active resources as suspended.
- LinkRegistry retains coordinate-typed viewport commits with group/domain
  identity. Linked targets can gesture, resize, switch groups and alternate
  source ownership without scalar drift.

## Upgrading from 0.1.4

Runtime API remains **2**, but 0.1.5 intentionally tightens pre-1.0 source and
theme contracts:

1. Update all three crates and reinstall the CLI at the same version.
2. Add `xxs` to every custom theme spacing map, normally 2px.
3. Run `gpui-rhai update` to merge the 0.1.5 component/motion/chart snapshot,
   then review conflicts and run `gpui-rhai check`.
4. For linked or independently scaled charts, persist `proposal.viewport` and
   `proposal.viewport_revision`; zoom/pan-only state cannot express every X/Y
   combination.
5. Native Rust may read custom semantic colors by exact namespaced key through
   `PrimitiveTheme::color`.
