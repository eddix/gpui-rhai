# 0.1.5 release notes (draft)

0.1.5 keeps Runtime API 2 and adds an optional native Chart Runtime. It is not
an ECharts compatibility layer: Rhai uses GPUI Rhai's typed component, theme,
Motion, event, data, extension, and security boundaries.

Highlights:

- Button/Badge now have deliberately different action-versus-label density.
  Tabs adopts one continuous 3px-inset track, content/equal layout, icon and
  icon-only headers, typed style parts, and a shared-layout indicator animation
  with Reduced/None policy inherited from Motion Runtime.
- Cartesian2D, Polar, and Host-owned Geo2D regions can be composed in one
  chart, including multiple named axes and grids.
- Bar/Stacked Bar, Line/Area, Scatter, Pie/Donut, Heatmap,
  Map/Choropleth, GeoScatter, GeoLines, Candlestick, Radar, Gauge, and Funnel
  share one prepared paint/hit/semantic/export scene.
- Small Rhai rows become typed columns once. Revisioned `NativeChartData`
  supports atomic replace, concurrent-safe append, and sliding windows without
  per-update Rhai execution.
- Native filter/sort/aggregate/bin/stack/normalize/moving-window/downsample
  transforms preserve original datum identity where semantics permit;
  categorical Line/Area sampling retains the original category values.
- Tooltip, crosshair, zoom/pan, brush, controlled selection/legend/viewport
  with an explicit `viewport_revision` proposal acknowledgement,
  keyboard navigation, linked charts, and annotations stay on native hot paths.
- Chart subscriptions, candidate tasks, and active gestures participate in
  retained view suspend/resume; streaming bursts rebuild only the latest
  revision after resume, and aggregated transitions resume from frozen time.
- Aggregated keyed geometry transitions reuse Motion Runtime policy and theme
  easing/duration roles, including reduced and disabled motion.
- All themes receive derived `charts.*` palette/axis/grid/tooltip/semantic
  tokens. Active locale number metadata, explicit timezones, and trusted Rust
  formatter extensions drive labels.
- Hosts register licensed GeoJSON/SVG maps, equirectangular/Mercator or custom
  projections, transforms, formatters, and validated custom series. No map
  data, network access, geocoding, dynamic plugin, or per-datum Rhai renderer
  is bundled.
- Host-only terminal SVG and PNG export consumes the same prepared scene.
- The post-implementation contract audit closed shared-axis, signed-stack,
  transform-schema, null-gap, Gauge/Radar domain, controlled viewport, typed
  identity, PNG font, accessibility, duplicate-registration, and adapter
  normalization failures before release. Mathematical, public API, and real
  GPUI input tests now guard these contracts.
- `gpui-rhai add chart` enables the Cargo feature and installs the generic
  source component. Formal Bar/Line/Pie/Map adapters and additional exported
  single-kind adapters provide ergonomic entry points and share the complete
  controlled viewport protocol.
- `chart_gallery` mounts every built-in series, loads all bundled themes and
  locales, and exercises a Host map, annotations, and a 100,000-row native line dataset. The end-to-end
  performance harness records resize and streaming revisions and asserts zero
  Rhai operations on the stream path.

The release also adds validated Host-wide `ThemeTokenOverrides`, including
partial color, spacing, radius, typography, motion, and namespace preferences
across every default/additional/user theme and hot reload.

Explicit later work: Graph, Tree, Treemap, Sunburst, Sankey, freehand lasso,
PDF/video/animated SVG, mark editing, 3D, and Globe.
