# gpui-rhai 0.1.2

0.1.2 froze the first complete 51-component foundation before work moved to
the generic Motion runtime.

## Highlights

- Weighted Table flex columns, native divider drag/keyboard resize and bounded
  GPUI-measured double-click auto-fit.
- A consistent dense-desktop typography scale across all 15 bundled themes.
- Explicit accessibility semantics for fields, choices, navigation, menus,
  overlays, progress, icons and dividers.
- Clear IconButton/Button/inline-SVG responsibilities and synchronized CLI,
  editor metadata, Theme Studio, Component Gallery and examples.

## Breaking component-schema change

`Input`, `Textarea`, `Combobox`, `Select`, `DatePicker`, `Pagination`, `Menu`,
`ContextMenu`, `Popover`, `Tooltip` and `Progress` require an explicit `label`.
The pre-1.0 release intentionally provides no placeholder-derived compatibility
fallback.

After updating, reinstall/update the registry sources and add the missing labels
before running `gpui-rhai check`.
