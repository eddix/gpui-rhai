# gpui-rhai 0.3.1

Release date: 2026-10-28. A patch release, compatible with 0.3.0. Runtime API
stays **3**, gpui-pre/core/platform stay 0.3.7 and MSRV stays 1.95. Upgrade
core, registry and CLI together.

It adds Carousel, a controlled pager for compact places, and SlidingPanel,
which brings new content in from the side it comes from; Tabs can slide its
panels the same way. It also fixes disabled icons that kept their enabled
color and scroll containers that scrolled a viewport past their end. The full
list is in the [CHANGELOG](../../CHANGELOG.md).

## New

- **Carousel** (`components/carousel`) shows one item at a time and never
  turns by itself. `variant: "header"` puts the label and the controls above
  the item; `"overlay"` lays arrows over its sides, shown on hover or focus.
  The position is a count (`2 / 5`), dots or nothing, and `wrap` steps past the
  ends. Its controls are one tab stop beside the item, so keys typed in a field
  or list inside an item stay the item's. See decision D72.
- **SlidingPanel** (`components/sliding_panel`) slides new content in 12px
  with a fade from the side it comes from, mirrored in right-to-left text and
  settled by the Host's motion policy. Only the incoming content moves, so any
  content can slide.
- **Tabs** takes `panel_motion: "slide"` (with `key`) to slide a newly
  selected panel in from the side of the tab it replaces; AnimatedTabs
  forwards it.

## Fixes

- A disabled IconButton, and the `prefix`/`suffix` icons of a disabled Button,
  now take the `disabled` ink like the label.
- A scroll container whose box is not a flex container, such as ScrollArea's
  viewport, no longer scrolls a viewport's height past its last row. The
  runtime's overlay scrollbar is pinned to the container's origin instead of
  sitting after the content.

## Upgrading from 0.3.0

Upgrade the CLI first, then run `gpui-rhai update`:

- **Tabs** 0.3.1 imports `components/sliding_panel`, which `update` installs.
- **Button and IconButton** 0.3.1 carry the disabled-icon fix;
  **AnimatedTabs** 0.3.1 forwards `panel_motion`.
- **Carousel** is new: `gpui-rhai add components/carousel` installs it with
  SlidingPanel and the chevron icons.

The scroll fix is in the runtime crate, so it reaches every application with
the 0.3.1 dependency, without a source update. Merges keep local edits and
write conflicts to `.gpui-rhai/conflicts/`.
