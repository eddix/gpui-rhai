# gpui-rhai 0.1.4

0.1.4 is a Runtime API 2 hardening release driven by dogfooding. It does not
introduce a compatibility break or another component layer; it closes the
rendering, embedding, layout, and incremental-presentation gaps found after the
0.1.3 Motion Runtime release.

## Highlights

- SVG `currentColor` is a true inherited default rather than a textual
  replacement. Fixed colors, gradients, opacity/alpha, document-local `color`,
  text, generic families, and platform fallback are preserved through the
  GPUI 0.2.2 channel-order adapter.
- Public async image decode now performs SVG parsing, font resolution,
  rasterization, encoding, and image preparation off the foreground thread.
  Cold inline/tint variants use the GPUI background executor and a shared
  256-entry/128-MiB LRU with cancellation tokens and observable cache counters.
- `HostSlotRegistry` lets a Rhai shell place Host-owned elements, entities, or
  independently mounted script views without transferring event or lifecycle
  authority. Cross-Host views retain their own container frame.
- Combobox and Select can match their deferred overlay to the realized trigger
  width, including relative/flex layouts and resize.
- IconButton adds controlled selected/pressed semantics while transparent and
  secondary variants retain their intended container treatment.
- Inherited `motion_group` membership survives component-local incremental
  rerender, nested replacement, and later virtual-item realization.

## Compatibility

- Runtime API remains **2**.
- Existing 0.1.3 Rhai applications do not need a runtime migration.
- The versioned registry snapshot advances every official component and motion
  source to 0.1.4 so CLI `diff`/`update` can track this release exactly.
- A cold externally tinted SVG may now resolve through asynchronous
  `ImageSource::Custom` rather than being immediately available as
  `ImageSource::Image`; application UI repaints automatically. Rust code must
  depend on the declared `ImageSource` contract, not a concrete enum variant.

## Verification

- MSRV 1.94 and latest stable checks, strict all-target/all-feature Clippy,
  workspace/default-feature tests, rustdoc, package verification, release
  builds, and release-artifact audits pass in protected CI.
- The all-feature core baseline is 401 unit tests; the official registry has 49
  cases, the CLI 24, and the independent native workspace 65.
- The target manifest covers 22 examples and all 38 PNG baselines pass their
  structural audit.
- The original 2048×2048 async SVG foreground drain measurement fell from
  roughly 18.06 ms to roughly 0.010 ms on the reference Apple M1 run.
- Dogfooding acceptance completed for the 0.1.4 issue set. Detailed independent
  evidence is retained in the
  [issue-fix audit](../audits/2026-09-21-issue-fixes-6373e4b3/report.zh-CN.md)
  and its
  [SVG acceptance follow-up](../audits/2026-09-21-issue-fixes-6373e4b3/acceptance-050c7fa2/report.zh-CN.md).

## Known boundaries

- One presentation domain may have only one live owner for a shared-layout
  identity. Handoff uses the runtime snapshot/exit ghost rather than two
  simultaneously live owners.
- SVG text uses the system `usvg` font database. Host-provided in-memory
  `FontSource` values apply to GPUI text but are not injected into that separate
  SVG database.
- General 3D, arbitrary shader source, final screen-reader/platform matrices,
  and full 120 Hz certification remain outside this release.
