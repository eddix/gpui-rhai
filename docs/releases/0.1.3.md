# gpui-rhai 0.1.3

0.1.3 introduced Motion Runtime 2, shared by Rust extensions and Rhai-authored
interfaces.

## Highlights

- Typed transitions, springs, keyframes, inertia, timelines, scoped controls,
  replay keys and deterministic clocks.
- Native hover/press/focus, in-view, viewport, scroll-progress and pointer-
  velocity sources without per-frame Rhai execution.
- Enter/exit ghosts, committed-geometry layout motion, shared layout, RichText
  span opacity and Canvas transform/path/morph motion.
- Reduced-motion and quality policy, semantic motion theme tokens, lifecycle/
  cost budgets and transactional reconciliation.
- Ten optional `motion/*` source components and the Motion Gallery.

## Breaking runtime change

Runtime API **2** replaces `.animate`, `transition`, `spring` and
`loop_transition`; the old prototypes have no aliases. Migrate to the APIs in
[the Motion guide](../motion.md) and update copied `motion/*` sources together
with the runtime.
