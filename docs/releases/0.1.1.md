# gpui-rhai 0.1.1

0.1.1 hardened the runtime and made application-owned component styling a
formal API.

## Highlights

- Globally unique program/component/mount/presentation identities and isolated
  multi-window geometry, callbacks, timers and signals.
- Lifecycle/state/Engine transactions now roll back async authority and
  cancellation atomically; subscriptions and background work are bounded.
- Durable values, operation budgets, restricted imports and diagnostic
  redaction were hardened for Rhai 1.26.
- Formal node-prop components replay current caller-owned snapshots; virtual
  collections, Command and Combobox use one interaction owner.
- View suspend/resume, structured diagnostics, CodeViewer/DiffViewer fixes and
  typed global component stylesheets.

## Breaking source change

The global `component_style(props, part, base)` helper was removed. Component
sources call `ctx.component_style(part, base)` so ordinary, retained and
deferred renderers use the same validated stylesheet snapshot.

Upgrade the three crates and run `gpui-rhai update` followed by
`gpui-rhai check`.
